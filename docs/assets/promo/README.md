# Codex Usage Menu 宣传素材

基于作者提供的四张真实产品截图制作。原始截图保留在项目本机的 `参考图/`，
该目录已加入 Git 忽略项，防止包含账户信息的原图随源码公开。

## 成品

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| promo-overview.png | 2400 × 1500 | 主宣传图，浅色 / 深色收起状态 |
| promo-reset-details.png | 2400 × 1800 | 重置权益详情，浅色 / 深色展开状态 |
| screenshot-light.png | 1118 × 622 | 浅色收起实拍，脱敏清理版 |
| screenshot-light-expanded.png | 1144 × 1096 | 浅色展开实拍，脱敏清理版 |
| screenshot-dark.png | 1144 × 778 | 深色收起实拍，脱敏清理版 |
| screenshot-dark-expanded.png | 1202 × 1178 | 深色展开实拍，脱敏清理版 |

主图与详情图使用真实面板像素，不由生成模型重绘界面。
账户标题统一替换为 `demo@example.com`，其余账户套餐、额度、日期、按钮和文案沿用实拍。
顶部移除网速组件与红框，让 Codex 额度后直接相邻 Spotlight 放大镜，约保留 14.5 pt 间距。
原始图像的其他系统图标在清理版中保留；宣传版只展示与产品相邻的状态栏局部。
该位置调整仅用于宣传素材，没有改动应用运行时或用户的系统菜单栏。

## 制作方式与校验

- 背景：直接取自原始截图中小组件后方的蓝色桌面区域，铺满整张画布；面板不再套独立背景卡片。
- 面板与文字：通过 AppKit / Core Graphics 做确定性的像素合成。
- 真实界面的截图面板以 1:1 原始像素置入宣传画布，未进行透视变形或界面重设计。
- 对四张清理版进行像素比对：排除顶部 56 px 和账户标题替换区域，
  其余超过 396 万像素未出现大于 1/255 的通道偏差；顶部未残留红框像素。
- 已检查浅色与深色模式、弹窗箭头、放大镜间距、完整重置详情和脱敏区域色差。
- 本机离线 OCR 在四张清理版中均仅识别到示例邮箱；六张最终图的识别结果中均未出现其他邮箱或网速文字。

蓝色背景为 `backdrop.png`，由合成脚本从脱敏截图的无界面区域提取。宣传文字改用白色，与蓝色背景统一。

可在 macOS 上复现像素编辑与排版：

```bash
clang -fobjc-arc scripts/render_promotions.m -framework Cocoa -o /tmp/codex-promo-render
/tmp/codex-promo-render "$PWD" "$PWD/docs/assets/promo"
```

需要本机保留四张原始截图；不会连接 Codex，也不读取真实账户数据。
所有 PNG 是扁平化输出，无编辑图层或隐藏的账户原文。
